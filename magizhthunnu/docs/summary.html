1. Executive Summary

Magizhthunnu is a scalable online food delivery platform connecting customers with local restaurants. The system enables users to browse restaurants, order food, make payments, and track deliveries in real time.

Primary Goals

  • Seamless food ordering
  • Fast restaurant discovery
  • Secure payment processing
  • Real-time order tracking
  • Scalable microservice-friendly architecture

2. High Level Architecture

graph LR Client[React Frontend] API[Express API] DB[(MongoDB Atlas)] Redis[(Redis Cache)] Queue[(BullMQ Queue)] Paytm[Paytm Gateway] Cloudinary[Cloudinary] Client --> API API --> DB API --> Redis API --> Queue API --> Paytm API --> Cloudinary

Architecture follows a 3-tier model

  • Presentation Layer – React SPA
  • Application Layer – Node.js + Express
  • Data Layer – MongoDB + Redis
